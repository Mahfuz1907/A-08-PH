# Studio Space — Studio Management & Booking Platform

A modern, responsive full-stack studio management web application built with Next.js 14, TypeScript, Tailwind CSS, and MongoDB. Studio Space allows creators to discover, list, and book recording booths and creative studio spaces effortlessly.

🌐 **Live Site URL:** [https://your-live-website-link.vercel.app](https://your-live-website-link.vercel.app)

---

## 🌟 Key Features

- **Studio Listing Management:** Seamlessly add, update, and manage studio listings with dynamic pricing and amenities.
- **Interactive Booking System:** Browse available creative spaces, select time slots, and track active bookings in real-time.
- **SEO-Optimized & Dynamic Routing:** Built with Next.js App Router featuring Server Component metadata generation to avoid title flickering and boost search performance.
- **Robust Error Handling & Loading States:** Integrated global error boundaries (`error.tsx`), suspense fallbacks, and Skeleton UI states for reliable user feedback.
- **Responsive Dashboard:** Interactive Overview Hub with real-time stats cards, dark/light theme support, and user profile summaries.

---

## 🛠️ Tech Stack

- **Framework:** Next.js 14 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS, Shadcn UI / Lucide React Icons
- **Database & ORM:** MongoDB & Mongoose
- **Authentication:** Better Auth / Custom Auth Flow
- **Deployment:** Vercel
